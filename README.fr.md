# Espaces Modulaires Open Source

Nous avons formaté notre monde pour les voitures, mais nous avons peu d'autre chose pour utiliser tout cet espace que nous avons cédé à ces machines. Un Thiosphere™ est créé pour combler ce vide avec un but et une beauté qui définissent son design audacieux et efficace. C'est du Hardware Open Source que n'importe qui peut construire et modifier selon ses propres besoins.

## Introduction

Un thiosphere est fabriqué avec le minimum de pièces possible, mais résulte en un espace modulaire fort, léger et spacieux qui n'occupe que 1/2 d'une place de stationnement. Il est emballable à plat et peut être assemblé avec des outils communs. Il est modulaire pour que vous puissiez créer un nombre infini d'espaces, d'un simple abri à un bureau complexe. Il est à la fois fonctionnel et beau, et conçu pour être un second lieu où la vie peut s'épanouir - quoi que ce soit et où que soient ces exigences.

## Les Avantages

- **Construit Fort** : Géométrie sphérique = force maximale, matériau minimal
- **Reste Frais** : La convection naturelle maintient l'environnement stable à l'intérieur
- **S'Intègre Parfaitement** : Conçu pour les places de stationnement existantes - aucune modification nécessaire
- **Facile à Construire** : Géométrie simple signifie que vous pouvez le faire localement avec des outils de base
- **Intelligent en Énergie** : Design passif réduit les besoins énergétiques de 80%

## Guide de Construction

### Ce Dont Vous Avez Besoin

**Matériaux :**
- 180 - planches 2x4
- 4 - feuilles de contreplaqué 4'x8'
- 120 - écrous et boulons
- 800 - vis à bois
- 4 roulettes, une petite remorque ou un socle de nivellement (optionnel)

**Outils :**
- Scie à onglets composés
- Scie à table ou scie circulaire
- Perceuse/visseuse
- Mètre ruban
- Crayon
- Équipement de sécurité (lunettes, protection auditive)

### Construction Étape par Étape

#### 1. Préparer le Bois

**Couper les 2x4 à longueur :**
- **Dôme extérieur** : pièces de bord de 20,67"
- **Dôme intérieur** : pièces de bord de 19,38"

**Dégauchir les 2x4 pour les pièces de bord :**
- Régler la scie à table à un angle de biseau de 19,8°
- Dégauchir les 2x4 pour créer des pièces de bord angulées
- Vous aurez besoin d'environ 60 pièces pour le dôme extérieur, 60 pour le dôme intérieur

#### 2. Couper Ces Angles

**Pour Dôme Extérieur (8' diamètre) :**
- **Joints hexagone à hexagone** : angle composé de 20,91°
- **Joints hexagone à pentagone** : angle composé de 18,69°
- **Joints hexagone** : angle de 30°
- **Joints pentagone** : angle de 36°

**Pour Dôme Intérieur (7,5' diamètre) :**
- Mêmes angles que le dôme extérieur
- Toutes les pièces sont plus courtes (19,38" vs 20,67")

#### 3. L'Assembler

**Commencer par l'anneau de base :**
1. Disposer votre premier anneau de pièces sur une surface plane
2. Joindre les pièces en utilisant les angles calculés
3. Utiliser des vis GRK pour sécuriser les joints
4. Vérifier la rondeur et ajuster au besoin

**Construire vers le haut en anneaux :**
1. Chaque anneau se connecte à celui du dessous
2. Maintenir un espacement cohérent entre les dômes intérieur et extérieur
3. Utiliser des supports temporaires pour maintenir les pièces en place
4. Travailler par sections pour le maintenir solide

#### 4. Ajouter les Panneaux

**Couper les panneaux de contreplaqué :**
- Mesurer chaque ouverture entre les pièces du cadre
- Couper les panneaux pour s'adapter avec 1/4" d'espace pour l'expansion
- Poncer les bords lisse

**Installer les panneaux :**
1. Appliquer du mastic silicone sur les bords du cadre
2. Presser les panneaux en place
3. Sécuriser avec des vis autour du périmètre
4. Essuyer l'excès de mastic

#### 5. L'Étanchéifier

**Sceller tous les joints :**
- Appliquer du mastic silicone sur tous les joints extérieurs
- Porter une attention particulière aux bords des panneaux
- Laisser durcir pendant 24 heures

**Appliquer la finition :**
- Peindre ou sceller toutes les surfaces de bois
- Utiliser de la peinture de qualité extérieure pour usage extérieur
- Appliquer plusieurs couches pour la durabilité

### Conseils Pro

- **Prenez votre temps** : La précision dans la coupe des angles est clé
- **Ajustement d'essai** : Assembler les sections à sec avant l'assemblage final
- **Utiliser des gabarits** : Créer des gabarits simples pour maintenir les pièces aux angles corrects
- **Travailler à deux** : Certaines étapes d'assemblage sont plus faciles avec de l'aide
- **Vérifier les mesures** : Vérifier chaque pièce avant de couper

### Ressources

- [Calculateur de Scie à Onglets Composés](https://jansson.us/jcompound.html) - Essentiel pour calculer des angles précis
- [Vis GRK FIN/Trim™](https://grkfasteners.ca/product/fin-trim-finishing-trim-head-screw/) - Recommandé pour une finition propre
- [Hardware McMaster-Carr](https://www.mcmaster.com/90273A572/) - Pour des fixations et du hardware supplémentaires

### Référence Rapide

Dôme Extérieur (8' diamètre) :
- Longueur de bord : 20,67"
- Diamètre pentagone : 23,88"
- Diamètre hexagone : 35,18"

Dôme Intérieur (7,5' diamètre) :
- Longueur de bord : 19,38"
- Diamètre pentagone : 32,98"
- Diamètre hexagone : 22,38"

Angles Clés :
- Hex à hex : 20,91°
- Hex à penta : 18,69°
- Joints hex : 30°
- Joints penta : 36°
- Angle de dégauchissage 2x4 : 19,8°
