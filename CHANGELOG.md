## [0.1.0] - 2024-01-XX

### Added
- Initial project release
- Basic Thiosphere design documentation
- CAD models (STEP and STL formats)
- Construction guide
- CERN Open Hardware License v2 implementation
- Design principles and philosophy
- Modular system architecture
- Material specifications
- Tool requirements
- Assembly instructions

### Technical Specifications
- Dual-sphere design (8' outer, 7.5' inner diameter)
- 180 pieces of 2x4 lumber
- 4 sheets of 4'x8' plywood
- Modular connection system
- Flat-packable design
- Parking space compatible footprint

### Design Features
- Spherical geometry for maximum strength
- Natural convection cooling
- Passive design principles
- Modular expansion capability
- Standard tool compatibility
- Weather-resistant construction
